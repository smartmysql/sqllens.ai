# Build & distribution

This folder documents how **SQLLens.AI** is shipped to users. It does **not** contain compiled extension binaries or TypeScript source.

## How users get the product

| Channel | Notes |
|---------|--------|
| [VS Marketplace](https://marketplace.visualstudio.com/items?itemName=skylineai.sqllens) | Primary install for VS Code and compatible editors |
| `extension-manifest.json` | Snapshot of `name`, `version`, `publisher`, `engines` from the release build |

## `extension-manifest.json`

Regenerated by the maintainer sync script from the development repository’s `package.json`. Use it for:

- CI badges or release notes that need the current version string  
- Enterprise inventory (publisher ID, engine minimum)  
- Docs that reference the extension ID `skylineai.sqllens`

## What is not in this public repo

- `src/`, `out/`, webpack bundles, webview sources  
- `node_modules/`, API keys, or connection secrets  
- Full `package.json` scripts and dependency trees  

To build from source, use the private development repository and its documented `npm run dev` / `npm run watch` workflow.
